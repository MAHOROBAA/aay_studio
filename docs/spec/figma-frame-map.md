## 참고

- "템플릿 적용 - stepN" / "직접 만들기 - stepN"이 스펙 5.4~5.8의 어느 화면(캐릭터 설정, 검토, 게시 설정 등)에 해당하는지는 각 프레임을 실제로 열어 내용을 확인하며 정리한다. 확인되는 대로 이 표의 "대응 스펙" 칸을 구체화한다.
- "영상 생성 중"(5.6) 화면에 해당하는 프레임명이 목록에 없다. 위 step 프레임 중 하나에 포함되어 있을 수 있으므로, 5단계(생성 중/검토/게시) 작업 시 확인한다.
- 이 표는 Figma 파일이 수정되면 최신 상태가 아닐 수 있다. node id 조회가 실패하면 이 표를 맹신하지 말고 `get_metadata`로 재확인한다.
