1단계(프론트엔드 기반)가 완료된 뒤 진행한다. VS Code Claude Code 채팅창에 아래 내용을 그대로 붙여넣는다.

## 프롬프트

AAY Studio 개발 명세(`docs/spec/aay-studio-spec.md`)의 11장 "구현 우선순위" 중 **2단계: 정적 화면**을 진행하되, 이번에는 다음 3개 화면만 만들어줘.

- 5.1 랜딩 (`/`)
- 5.2 홈 (`/home`)
- 5.3 작업 방식 선택 (`/create`)

`CLAUDE.md`의 행동 지침을 따르고, 1단계에서 만든 공통 컴포넌트(Button/Input/Dropdown/Popup)와 레이아웃(Header/Sidebar/AppLayout), 라우터, 전역 스타일 토큰을 그대로 재사용해줘. 새 공통 컴포넌트가 필요하면 만들기 전에 나에게 먼저 설명해줘.

화면 수치와 레이아웃은 Figma MCP(`figma-desktop`)로 해당 프레임(랜딩/홈/작업 방식 선택)을 직접 조회해서 확인해줘. 프레임을 못 찾겠으면 어떤 프레임을 열어서 알려줘야 하는지 나에게 물어봐줘.

### 화면별 요구사항 (스펙 5.1~5.3, 8.1 참고)

**랜딩 (`/`)**
- 서비스명, 핵심 설명, "Google로 계속하기" CTA를 배치한다.
- 이번 단계는 정적 화면만 만드는 단계이므로 실제 Google 로그인 연동은 하지 않는다. 버튼 클릭 시 동작은 자리표시자(TODO 주석 없이, 실제 함수 자리만 비워두는 방식)로 둔다.
- 로그인 상태에 따른 리다이렉트 로직(8.1)은 이번 단계에서 구현하지 않는다 — 3~4단계 범위.

**홈 (`/home`)**
- 템플릿으로 만들기 안내, 직접 만들기 안내, 만들기 진입 CTA를 배치한다.
- 방식 설명 문구는 왼쪽 정렬한다(스펙 5.2 "문구 정렬").
- 이번 단계에서는 로그인 이후 레이아웃(AppLayout, Header/Sidebar)을 적용한 상태로 정적 내용만 채운다.

**작업 방식 선택 (`/create`)**
- "템플릿으로 만들기", "직접 만들기" 두 선택지를 카드 형태 등으로 배치한다.
- 각 선택지 설명 문구는 가운데 정렬한다(스펙 5.3 "문구 정렬").
- 선택 시 각 플로우 첫 화면(`/create/template`, `/create/manual`)으로 이동하는 라우팅 연결만 하고, 실제 해당 화면 내용은 이번 단계에서 만들지 않는다(다음 배치에서 진행).

### 하지 않을 것

- 이번 배치에 없는 화면(템플릿 플로우, 직접 만들기 플로우, 검토/게시, 라이브러리, 마이페이지 등)은 만들지 않는다.
- 실제 Google 로그인, 라우트 가드(비로그인 접근 차단) 등 상태/인증 로직은 만들지 않는다.
- Figma에 없는 문구나 레이아웃을 추측해서 추가하지 않는다.
